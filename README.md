# Workflow Automation Service

Durable tenant-safe workflow execution with versioned DAGs, leases, heartbeats, timers, retries, dead letters, deduplicated triggers, connectors, approvals, signals, compensation, live traces, and redrive.

Run `docker compose up -d`, `npm install`, `npm run check`, and `npm run build`. Production connectors require allowlists and real encrypted credential infrastructure; demo connectors are safe local implementations.
